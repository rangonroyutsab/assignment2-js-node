# Assignment 01 ‑ HTML & CSS: Sanctuary Cap Cana Resort

A fully responsive, modern, single-page booking landing page for a luxury resort, built entirely from scratch using plain HTML5 and CSS3. 

## Project Description
This project represents a comprehensive UI clone/implementation of a resort booking page. It demonstrates advanced CSS layouts, responsive design principles, and interactive UI components without the use of JavaScript. 

## Key Features
* **Modern CSS Layouts:** Extensive use of CSS `Grid` and `Flexbox` for complex alignments (image galleries, multi-column footers, and card grids).
* **CSS Variables:** Theming is handled via a robust set of CSS custom properties (`:root`) for easy color, spacing, and typography management.
* **Sticky Elements:** Features a sticky top navigation bar and a sticky booking widget/map sidebar that scrolls with the user.
* **Interactive FAQ:** Utilizes native HTML5 `<details>` and `<summary>` tags for a fully functional accordion—no JavaScript required!

## Sections Included
1. **Header:** Sticky navigation with logo, quick links, and a call-to-action hotline.
2. **Hero Gallery:** Asymmetrical grid layout showcasing resort imagery.
3. **In-Page Navigation:** Quick jump links to various sections.
4. **About & Amenities:** Descriptive text paired with a responsive bulleted list of perks.
5. **Resort Highlights & Activities:** Card-based UI displaying activities and features.
6. **Reviews:** Styled review cards with star ratings.
7. **Policies & FAQs:** Icon-driven policy grid and interactive collapsible FAQs.
8. **Location:** Embedded map placeholder and distance-to-airport information.
9. **Sidebar:** A floating "Check Availability" booking widget that transforms into a static block on mobile.
10. **Nearby Resorts:** Suggestion cards that utilize CSS horizontal scroll snapping on mobile.
11. **Footer:** Comprehensive site footer featuring a newsletter signup, multi-column sitemap, and localized selectors.

## Technologies Used
* **HTML5:** Semantic markup (`<header>`, `<main>`, `<section>`, `<aside>`, `<nav>`, `<details>`).
* **CSS3:** Custom properties, Media Queries, Flexbox, CSS Grid, Transitions, and Scroll-snapping.
* **Typography:** [Google Fonts](https://fonts.google.com/) (Marcellus for headings, Open Sans for body text).
* **Icons:** [FontAwesome 6.4.0](https://fontawesome.com/) via CDN.
* **Images:** Placeholder images sourced from [Unsplash](https://unsplash.com/).

## How to Run the Project
Since this project is built with plain HTML and CSS and bundled into a single file (or a paired HTML/CSS file), no build tools or servers are required.

1. Clone or download the repository to your local machine.
2. Ensure you have an active internet connection (to load the Google Fonts, FontAwesome icons, and Unsplash images).
3. Open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge).
